MSFS SkyVector Connector v1.1
-----------------------------
Installation:
1. Extract all files into a single folder.
2. Run SkyVector_Server.exe.
3. Keep the console window open while flying.
4. If you see "Connected to Microsoft Flight Simulator," you are good to go!
5. To stop server, go to system tray.

Requirements:
- Microsoft Flight Simulator (2020/2024)
- SkyVector Browser Extension (configured to localhost:8001)

Troubleshooting:
- If the plane doesn't move, ensure SimConnect.dll is in the same folder as the .exe.
- Ensure your firewall allows local traffic on port 8001.
- Don't forget I don't have an official signature, so you may get a virus warning. 
- Windows may ask if is okay to run a "node based server" in your system; you know the answer. 
  (Windows Firewall has blocked some features of Node.js JavaScript Runtime on all public an
   private networks. "Node.js JavaScript Runtime"  --- Allow  ---   Cancel  ---).
